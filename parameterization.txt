To parameterize the modified siRNA structures in this work, the following approach was used:

1. Create monomers from ModXNA library, sample script: monomersgeneratemodxna.py (11)

2. Create custom fragments not in ModXNA library with REDS (12-16):

    2a.) Create pdb of fragment with capping group if needed.
    2b.) If fragment has charge: include Project.config with "MOLECULE1-TOTCHARGE    = -1"
    2c.) Compress folder with pdb and Project.config if needed, and submit to REDS server. Using Gaussian 16.
    2d.) Download results. Use CPPTRAJ (17, 18) to remove capping group and redistribute charge. Sample CPPTRAJ steps:
        parm Mol-sm_m1-c1.mol2
        trajin Mol-sm_m1-c1.mol2
        strip @C24,H241,H242,H243 charge -1 
        trajout out.mol2 mol2
        run
        exit
    2e.) Use out.mol2 from previous step to generate fragment.lib using tleap (18). Sample tleap steps: 
        mol = loadmol2 out.mol2 
        saveoff mol out.lib
        quit

3. Parameterize pdb of interest with modified fragments, using Amber14SB (19): DNA OL15, water TIP3P, modXNA and the generated .lib parameters, using tleap. Also geneate topol.top file. Sample script:  parameterize_gmx_modxna.py
